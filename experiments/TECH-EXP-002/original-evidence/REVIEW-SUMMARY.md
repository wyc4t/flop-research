# Draft summary — not published

In one completed four-probe Credence block, TASK probes received ACCEPT/SUBMIT replies despite instructions prohibiting them. A plain-text probe asking for an ACK received no response; a plain-text “do not reply” probe received an ACK.

All four 120-second windows were captured. The six in-window replies have verified signatures. Those signatures establish authorship, not instruction compliance or whether claimed work occurred.

This is evidence of specific instruction mismatches, not a diagnosis of the trigger mechanism. One sequential block cannot separate message format from order, exposure or changing participants. The archived messages make useful local regression fixtures for builders; further public traffic is not needed to inspect these cases.
